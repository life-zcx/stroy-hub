# Автономный Почтовый Сервис для Tormag (`tormag.kz`)

Данная директория содержит **полностью независимый почтовый сервис** на базе **Stalwart Mail Server** (почтовый сервер нового поколения на Rust) и **Roundcube Webmail** (веб-клиент для работы с почтой).

Сервис работает изолированно от основного сайта в своих Docker-контейнерах и не зависит от кода основного приложения.

---

## 🚀 Быстрый запуск сервиса на сервере

Перейдите в папку сервиса на сервере и запустите контейнеры:

```bash
cd ~/stroy-hub/mail-service
chmod +x init-mail-service.sh
./init-mail-service.sh
```

После запуска будут доступны панели:
- **Панель управления Stalwart (Admin UI):** `http://IP_ВАШЕГО_СЕРВЕРА:8880`
- **Веб-почта (Roundcube Webmail):** `http://IP_ВАШЕГО_СЕРВЕРА:8890`

---

## 📋 Настройка DNS-записей для идеальной доставляемости (Inboxing 100%)

Чтобы ваши письма не попадали в спам в Gmail, Mail.ru и Яндекс, добавьте следующие записи в DNS вашего домена (`tormag.kz`):

### 1. A-запись (Сервер почты)
| Тип | Имя | Значение |
| :--- | :--- | :--- |
| **A** | `mail` | `IP_ВАШЕГО_СЕРВЕРА` |

### 2. MX-запись (Прием почты)
| Тип | Имя | Значение | Приоритет |
| :--- | :--- | :--- | :--- |
| **MX** | `@` | `mail.tormag.kz` | `10` |

### 3. PTR-запись (Reverse DNS / rDNS)
*Настраивается в панели вашего хостинга (VPS)*:
Укажите, чтобы `IP_ВАШЕГО_СЕРВЕРА` резолвился в `mail.tormag.kz`.

### 4. SPF-запись (Разрешение отправки)
| Тип | Имя | Значение |
| :--- | :--- | :--- |
| **TXT** | `@` | `v=spf1 ip4:IP_ВАШЕГО_СЕРВЕРА ~all` |

### 5. DKIM-запись (Цифровая подпись писем)
Сгенерируйте DKIM-ключ в административной панели Stalwart (`http://IP_СЕРВЕРА:8880` -> Settings -> DKIM) и добавьте TXT-запись:
| Тип | Имя | Значение |
| :--- | :--- | :--- |
| **TXT** | `stalwart._domainkey` | `v=DKIM1; k=rsa; p=СГЕНЕРИРОВАННЫЙ_ПУБЛИЧНЫЙ_КЛЮЧ...` |

### 6. DMARC-запись (Политика безопасности)
| Тип | Имя | Значение |
| :--- | :--- | :--- |
| **TXT** | `_dmarc` | `v=DMARC1; p=none; rua=mailto:admin@tormag.kz` |

## ✉️ Создание почтовых ящиков

В панели управления Stalwart (`http://IP_СЕРВЕРА:8880`):
1. Перейдите в раздел **Domains** и добавьте `tormag.kz`.
2. Перейдите в раздел **Accounts** -> **Create Account**:
   - `no-reply@tormag.kz` (для отправки кодов верификации из сайта).
   - `support@tormag.kz` (для поддержки клиентов).
   - `admin@tormag.kz` (для администратора).
3. Задайте надежные пароли для каждого ящика.

---

## 🌐 Использование веб-почты (Roundcube)

Для чтения входящих и отправки писем вручную откройте `http://IP_СЕРВЕРА:8890`:
- **Логин:** полный адрес электронной почты (например, `support@tormag.kz`).
- **Пароль:** пароль, созданный в Stalwart Admin UI.

---

## 🔌 Подключение к backend `stroy-hub` (Отправка кодов верификации)

В файле `.env.production` вашего бекенда укажите параметры SMTP нашего локального сервиса:

```env
SMTP_HOST=172.17.0.1  # или mail-server (если в одной docker-сети)
SMTP_PORT=587
SMTP_USER=no-reply@tormag.kz
SMTP_PASS=пароль_созданного_ящика
```

Сервис готов к работе!
